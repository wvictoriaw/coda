# coda README

vsc extension that helps me remove the things about AI coding assistants that make them a nightmare

### PSA: this extension is in dev; it hasn't been packaged yet! 

## Features

- Debugger that works on a "snippet" concept. What's a breakpoint? Never heard of her.
- Native chatbot maybe soon

## Support

- Only Python for now
- some localhost functionality for js/jsx/ts/tsx files

## How to run

1. Download the .vsix file
2. Go to your VSC extensions panel
3. Click on ... on the top right of the panel
4. Click *"Install from VSIX"*
5. Open the vsix file you just downloaded
6. Enjoy! cmd/ctrl + shift + c to launch
